# MCRI — Top 5 Founder Outreach Pack

**Status:** Drafts only. Nothing has been sent.  
**Goal of first outreach:** secure a 30-minute workflow discovery conversation, not sell software on first contact.

## Core positioning

MCRI is a human-in-the-loop H&M machinery-claims workspace that turns claim evidence into structured facts, missing-document checks, chronology, evidence conflicts, technical/financial review and a source-linked assessment. It does **not** automate coverage, liability, causation or settlement.

## First-call discovery objective

Do not spend the first 30 minutes showing every feature. Learn:

1. How many H&M/machinery cases the team handles in a normal year.
2. Who owns the file operationally.
3. Which documents consume the most review time.
4. How chronology is built today.
5. How missing documents are tracked.
6. How quotations/invoices are reviewed.
7. Where technical and insurance teams hand work off to each other.
8. What data/security restriction would block a pilot.
9. Whether anonymised closed files can be used for a controlled test.
10. Who else must be involved for a pilot decision.

## Commitment ladder

First conversation → permission for deeper workflow mapping → one synthetic demo → one anonymised closed-file test (if permitted) → controlled 30-day design-partner pilot → paid pilot.
