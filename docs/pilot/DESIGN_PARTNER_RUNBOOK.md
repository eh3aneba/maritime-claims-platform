# Design Partner Runbook

## Purpose

This runbook starts a **private synthetic design-partner environment** for the Maritime Claims & Risk Intelligence Platform. The included MT ORION claim is synthetic demonstration data only.

## 1. Prerequisites

- Docker Desktop / Docker Engine with Docker Compose v2
- At least 4 CPU cores and 8 GB RAM recommended for local pilot use
- Ports 3000, 8000 and 5432 available on the workstation
- Python 3.11+ only if running browser E2E from the host

Do not expose the development compose stack directly to the public internet.

## 2. Configure the pilot environment

```bash
cp .env.pilot.example .env
```

Replace every `REPLACE_WITH_*` value. Generate a strong application secret, for example:

```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

The database password in `POSTGRES_PASSWORD` and the password embedded in `DATABASE_URL` must match.

## 3. Run the automated preflight

```bash
./scripts/design_partner_preflight.sh .env
```

The script validates the compose file, builds the stack, runs Alembic migrations, executes application preflight checks, seeds MT ORION and checks API/web health.

Equivalent manual sequence:

```bash
docker compose --env-file .env up -d --build
docker compose --env-file .env exec -T api python -m app.core.preflight
docker compose --env-file .env --profile demo run --rm demo-seed
```

## 4. Sign in

Open `http://localhost:3000/login`.

Use the values configured in `.env`:

- Organization: `MCRI_DEMO_ORG_SLUG`
- Email: `MCRI_DEMO_EMAIL`
- Password: `MCRI_DEMO_PASSWORD`

The seeded account is a Claims Manager in the synthetic pilot organization.

## 5. Expected MT ORION walkthrough state

The seeded claim should show:

- Vessel: MT ORION
- External reference: `MCRI-DEMO-MT-ORION`
- Nine synthetic evidence documents
- Human-reviewed AI extractions generated by the deterministic fixture provider
- Missing Policy and Last Overhaul evidence
- Technical flags including maintenance interval/deferred maintenance review
- Reviewed chronology with a medium shutdown-time discrepancy
- Financial review with USD 25,000 reviewed invoiced cost and two non-cumulative quotation alternatives
- USD 575,000 reserve history
- Preliminary Initial Assessment with source-linked sections

The demo seed does **not** call OpenAI or another external AI provider.

## 6. Browser E2E

From the host workstation:

```bash
python -m venv .venv-e2e
source .venv-e2e/bin/activate  # Windows: .venv-e2e\\Scripts\\activate
pip install -r tests/browser/requirements.txt
playwright install chromium
export MCRI_DEMO_PASSWORD='<same value as .env>'
python tests/browser/design_partner_e2e.py
```

The E2E test covers login, claims search, claim overview, requirements, chronology, technical review, financial review, assessment and AI review navigation.

## 7. Resetting the demo

The demo seed is idempotent and will not duplicate MT ORION. For a clean reset of **synthetic local pilot data only**:

```bash
docker compose down -v
./scripts/design_partner_preflight.sh .env
```

`docker compose down -v` deletes the local PostgreSQL and evidence volumes. Never use it against a real pilot dataset unless data loss is explicitly intended.

## 8. Stop the environment

```bash
docker compose stop
```

To stop and remove containers while preserving named data volumes:

```bash
docker compose down
```
