# Sprint 11I — Separately authorized broader-production AI cohort

## Objective

Permit a separately governed, reversible Production cohort at 26–50% only after Sprint 11H records a positive readiness recommendation.

## Delivered controls

- positive 11H SHA-256 anchor and inherited 11G/11F evidence chain
- six distinct non-requesting approvals: Security, Privacy, Product, Operations, Risk, Claims Governance/Compliance
- Admin-only final authorization decision
- 26–50% deterministic rollout envelope with fixed claims/documents/users/provider-run caps
- CE Report and Engine Log only
- Internal/Confidential only; Restricted blocked
- fresh per-document legal basis and data minimization evidence
- queue-time and worker-time 11I precedence with fail-closed no-fallback behavior
- mandatory different-human review for each provider run
- live quality, grounding, latency, cost, incident and regression monitor
- automatic pause/rollback on monitor failure or incident
- explicit Admin recovery and kill switch
- immutable completion gate

## Exit condition

A completed 11I cohort does not widen rollout. Sprint 11J must measure the completed 26–50% cohort and may only recommend whether a separately governed next stage should be designed.

## Explicitly not authorized

Production-wide AI, rollout above 50%, Restricted documents, new document classes, autonomous claim decisions, and automatic authoritative claim-fact updates.
