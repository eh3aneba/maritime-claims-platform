# Sprint 7 — Real Browser UX Hardening

Sprint 7A converts findings from the first real browser walkthrough of MT ORION into claims-native presentation improvements.

## Scope
- Remove raw JSON measurements and internal UUIDs from Claim Handler views.
- Distinguish event importance from conflict severity.
- Show chronology source documents explicitly.
- Group financial line items by Invoice vs alternative quotation document.
- Improve Financial Summary and reserve presentation.
- Rewrite Initial Assessment sections into more professional claims language.
- Remove duplicate Recommended Next Actions.
- Mark overdue tasks in newly generated assessment versions.
- Lock approved assessment versions and require a new version for later edits.
- Consolidate fresh-host deployment hotfixes discovered during Windows/WSL/Docker testing.

## Out of scope
- New causation models.
- Automated coverage decisions.
- New claim types.
- Predictive reserves.
- Automatic counter-evidence conclusions.
